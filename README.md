# ML Practice Projects

This repository contains three basic machine learning practice projects:

## 1. House Price Prediction (Linear Regression)
- Implements linear regression to predict house prices
- Includes EDA, feature engineering, model training, and evaluation
- Uses synthetic data for practice

## 2. Exploratory Data Analysis (EDA)
- Comprehensive EDA on sales datasets
- Data cleaning, visualization, statistical analysis
- Missing values, outliers, correlation analysis

## Tech Stack
- Python
- NumPy, Pandas
- Scikit-learn
- Matplotlib, Seaborn
