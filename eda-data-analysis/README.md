# Exploratory Data Analysis (EDA) on Dataset

## Project Description

This project provides comprehensive Exploratory Data Analysis techniques on various datasets. It covers data cleaning, visualization, statistical analysis, and deriving meaningful insights from raw data.

This project is designed to teach essential data analysis skills that form the foundation of any data science or machine learning project.

## What You'll Learn

1. Loading and exploring datasets
2. Identifying missing values and handling them
3. Data type conversion and cleaning
4. Statistical summary and descriptive statistics
5. Data visualization using various charts:
   - Histograms and distribution plots
   - Box plots for outlier detection
   - Correlation heatmaps
   - Scatter plots and pair plots
   - Bar charts and pie charts
6. Feature engineering basics
7. Detecting and handling outliers

## Technologies Used

- Python 3.x
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Plotly (optional for interactive plots)

## How to Run

```bash
cd eda-data-analysis
pip install -r requirements.txt
python eda_analysis.py
```

Or use the Jupyter notebook:

```bash
jupyter notebook eda_analysis.ipynb
```

## Project Structure

- `eda_analysis.py` - Main Python script
- `eda_analysis.ipynb` - Jupyter notebook version
- `data/` - Dataset folder
- `visualizations/` - Saved plots

## Key EDA Steps Covered

1. **Data Loading**
   - Load from CSV, Excel, JSON
   - Understand data shape and structure

2. **Data Quality Check**
   - Check for missing values
   - Check data types
   - Identify duplicates

3. **Univariate Analysis**
   - Analyze each variable individually
   - Distribution analysis
   - Central tendency and spread

4. **Bivariate Analysis**
   - Relationship between two variables
   - Correlation analysis
   - Cross-tabulations

5. **Multivariate Analysis**
   - Pair plots
   - Correlation matrices
   - Grouped analysis

## Dataset

The project uses synthetic data representing a sales dataset with:
- Customer demographics
- Product information
- Sales data
- Customer ratings
