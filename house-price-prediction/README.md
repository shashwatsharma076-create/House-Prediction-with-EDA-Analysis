# House Price Prediction using Linear Regression

## Project Description

This project demonstrates a complete implementation of Linear Regression to predict house prices based on various features like square footage, number of bedrooms, bathrooms, etc. The goal is to understand the fundamentals of supervised learning and linear models.

## Dataset

- **Source**: Kaggle House Prices dataset (or synthetic data for practice)
- **Features**: Square footage, bedrooms, bathrooms, year built, location, etc.
- **Target**: House price

## What You'll Learn

1. Data loading and preprocessing
2. Feature engineering and selection
3. Training a Linear Regression model
4. Model evaluation using metrics (RMSE, R² Score)
5. Visualizing results and residuals

## Technologies Used

- Python 3.x
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## How to Run

```bash
cd house-price-prediction
pip install -r requirements.txt
python house_price_prediction.py
```

Or use the Jupyter notebook:

```bash
jupyter notebook house_price_prediction.ipynb
```

## Project Structure

- `house_price_prediction.py` - Main Python script
- `house_price_prediction.ipynb` - Jupyter notebook version
- `data/` - Dataset folder
- `models/` - Saved models
